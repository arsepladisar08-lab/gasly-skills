# Code of Conduct

## Our commitment

We want participation in GASLY Skills to be welcoming, respectful, constructive, and focused on improving the project for people with different backgrounds and levels of experience.

## Expected behavior

- Be respectful and considerate in discussions and reviews.
- Assume good intent while remaining open to correction.
- Give actionable feedback about code, documentation, and product behavior.
- Explain disagreements without personal attacks.
- Respect privacy. Do not publish credentials, private customer information, or private conversations.
- Keep criticism focused on the work rather than the contributor.

## Unacceptable behavior

- Harassment, threats, intimidation, or discriminatory language.
- Insults, personal attacks, or deliberate disruption.
- Publishing another person's private information without permission.
- Sharing secrets, exploit details, or private user data in public issues or pull requests.
- Knowingly submitting malicious code or misleading security claims.

## Scope

This code of conduct applies to project spaces, including issues, pull requests, code reviews, and other public channels used to discuss GASLY Skills.

## Reporting and enforcement

Report unacceptable behavior to the repository owner through the GitHub profile contact options. For security vulnerabilities, use the private process described in [SECURITY.md](SECURITY.md).

The maintainers may edit or remove content, close discussions, or restrict participation when needed to protect the community. Reports will be reviewed as fairly and confidentially as the available GitHub tooling allows.
