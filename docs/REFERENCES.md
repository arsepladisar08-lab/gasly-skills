# Catatan Referensi Eksternal & Lisensi (`docs/REFERENCES.md`)

Dokumen ini mencatat repositori eksternal yang dijadikan rujukan konseptual untuk arsitektur **gasly-skills**. Status `REFERENCED` berarti rujukan dipakai pada konteks tertentu, bukan audit menyeluruh atas seluruh file atau riwayat repository. Lisensi hanya dinyatakan jika dapat diverifikasi dari file lisensi sumber; ketiadaan file lisensi tidak boleh ditafsirkan sebagai izin penggunaan.

> **Kepatuhan Konten Orisinal:** Seluruh teks instruksi, aturan teknis, tabel pemetaan, skema token JSON, dan kode boilerplate di dalam repositori ini ditulis secara orisinal untuk arsitektur Google Apps Script (`/exec`) + Google Sheets + Google Drive milik Gasly. Tidak ada daftar aturan, tabel data, atau kode yang disalin dari repositori referensi di bawah ini.

Karena itu lisensi kedua repository tersebut ditandai `UNVERIFIED`; jangan menyalin kode, teks panjang, atau aset dari sana tanpa memastikan ketentuan lisensi pada file atau direktori yang relevan. Entri lisensi lain pada tabel adalah catatan dari sumber terdahulu dan tetap perlu diperiksa ulang sebelum ada pengambilan materi substansial.
