Langkah 2 — Jalankan Aksi 1-Klik setupAppEnvironment()

Tujuan: Menginisialisasi seluruh database, zona waktu, folder Drive, serta membuat AUTH_HMAC_SECRET & AUTH_PEPPER secara otomatis.
Aksi: Di toolbar Editor Apps Script, pilih fungsi setupAppEnvironment pada dropdown lalu klik Run (setujui dialog izin Google). Alternatif: muat ulang Google Sheets dan klik menu Gasly Setup > 1. Setup App Environment.
Hasil yang Diharapkan: Execution Log mencetak GASLY SETUP APP ENVIRONMENT REPORT dengan sheetsHealthy: true dan hmacSecretReady: true.
Sumber & Verifikasi: src/gas/config.md UNVERIFIED
Jangan buat manual: AUTH_HMAC_SECRET, AUTH_PEPPER, dan DRIVE_ROOT_FOLDER_ID sudah dibuat otomatis oleh setupAppEnvironment().

Langkah 3 — Kredensial Admin, ScriptProperties Matrix & Generator Secret

Tujuan: Menyimpan kredensial admin sebagai hash kriptografis di ScriptProperties tanpa pernah menulis plaintext di file .gs.
Aksi (Cara Termudah): Di Google Sheets, klik Gasly Setup > 2. Atur Passphrase & PIN Admin. Alternatif (Headless): Buka Project Settings > Script Properties, tambahkan ADMIN_PASSPHRASE_INIT (≥12 karakter) & ADMIN_PIN_INIT (6 digit), lalu klik Run setupAppEnvironment lagi.
Hasil yang Diharapkan: Execution Log menampilkan status: "READY_TO_DEPLOY" dan properti sementara *_INIT otomatis terhapus.
Sumber & Verifikasi: Apps Script Properties Service UNVERIFIED
Kunci ScriptProperties Tipe Cara Pengisian
AUTH_HMAC_SECRET, AUTH_PEPPER, DRIVE_ROOT_FOLDER_ID OTOMATIS Dibuat otomatis oleh setupAppEnvironment(). Jangan ditimpa manual.
ADMIN_PASSPHRASE_INIT, ADMIN_PIN_INIT SEMENTARA Isi sementara lalu jalankan setupAppEnvironment() (otomatis di-hash & dihapus).
ACCESS_PROFILE, GOOGLE_CLIENT_ID, WEBHOOK_SHARED_SECRET MANUAL Setel di Project Settings > Script Properties sesuai kontrak proyek.
Pembuat Secret Acak Lokal CSPRNG (crypto.getRandomValues — khusus properti manual) 
[Klik "Buat Secret 32-Kar" — hanya tampil di memori, hilang saat reload]

Langkah 7 — Uji Koneksi End-to-End (Multi-OS Copyable Snippets)

Tujuan: Memastikan endpoint {{GAS_EXEC_URL}} aktif, mengikuti redirect HTTP 302, dan mengembalikan JSON Envelope Kanonik.
Aksi: Pilih tab alat uji di bawah, klik salin, lalu jalankan dari terminal atau DevTools Console Anda (halaman ini tidak mengeksekusi panggilan jaringan).
Hasil yang Diharapkan: Respons JSON valid dengan status huruf kecil ("success" atau "error") — pada profil P4, items.list tanpa token harus mengembalikan code: "FORBIDDEN".
Sumber & Verifikasi: src/core/contract.md 2026-11-25
Jalankan di Terminal Mac/Linux/Git Bash

  -H 'Content-Type: text/plain;charset=utf-8' \
  -d '{"action":"items.list","v":1,"auth":null,"idem":null,"payload":{}}'
Jalankan di Windows PowerShell
$body = '{"action":"items.list","v":1,"auth":null,"idem":null,"payload":{}}'
Invoke-RestMethod -Method Post -Uri '{{GAS_EXEC_URL}}' -ContentType 'text/plain;charset=utf-8' -Body $body
Tempel ke DevTools Console di domain {{PAGES_DOMAIN}}
fetch('{{GAS_EXEC_URL}}', {
  method: 'POST',
  headers: { 'Content-Type': 'text/plain;charset=utf-8' },
  redirect: 'follow',

}).then(r => r.json()).then(console.log);

Troubleshooting & Pertanyaan Umum

1. Mengapa POST ke /exec membalas HTTP 302 Redirect?

Apps Script Web App selalu mengalihkan respons ke script.googleusercontent.com (src/core/facts.md, terverifikasi 2026-11-25). Pastikan klien menggunakan curl -L atau redirect: "follow".

2. Mengapa muncul error CORS / preflight OPTIONS gagal?

GAS tidak melayani preflight OPTIONS. Jangan gunakan application/json atau header kustom Authorization; wajib Content-Type: text/plain;charset=utf-8 dan letakkan auth di dalam body JSON (src/core/contract.md).

3. Mengapa file.ticket gagal VALIDATION_ERROR saat unggah foto publik?

Pastikan frontend meneruskan { entity, entityId, uploadNonce } yang diterima dari respons items.create ke aksi file.ticket dalam waktu maksimal 15 menit sejak record dibuat.

4. Mengapa aksi hapus (items.delete) ditolak FORBIDDEN meski sudah login Admin?

Aksi destruktif dilindungi Step-Up PIN 6 digit. Panggil auth.verifyPin ({ pin, targetAction: "items.delete" }) lalu sertakan stepUpToken pada payload items.delete.

5. Bagaimana cara memperbarui kode .gs tanpa mengubah URL /exec?

Buka Deploy > Manage deployments > Edit (pensil) > Version: New version > Deploy. Jangan klik New deployment (src/gas/config.md Seksi 3).

6. Berapa batas kuota runtime, konkurensi, dan email GAS?

Maksimal 6 menit/eksekusi, 30 eksekusi simultan per akun, dan kuota MailApp 100/hari (konsumen) atau 1.500/hari (Google Workspace) (src/core/facts.md, 2026-11-25).
