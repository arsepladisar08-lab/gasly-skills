Langkah 2 — Klik Run setupAppEnvironment() (Auto-Create DB & Drive)

Tujuan: Membuat file Google Spreadsheet + semua tab tabel + 16 data contoh + Folder Google Drive + AUTH_HMAC_SECRET & AUTH_PEPPER dalam 1 kali klik.

Langkah 3 — Atur Passphrase & PIN Admin (Nol Plaintext di Kode)

Tujuan: Menyimpan hash kriptografis passphrase & PIN admin ke ScriptProperties dengan aman.
Aksi: Buka Project Settings (roda gigi) > Script Properties → tambahkan properti sementara ADMIN_PASSPHRASE_INIT (≥12 karakter) dan ADMIN_PIN_INIT (6 digit angka) → Simpan → kembali ke Editor dan klik Run setupAppEnvironment sekali lagi.
Hasil yang Diharapkan: Log menampilkan status: "READY_TO_DEPLOY" dan properti sementara *_INIT otomatis lenyap dari Script Properties.
Sumber: Apps Script Properties UNVERIFIED
Generator Secret Acak Lokal CSPRNG (crypto.getRandomValues — untuk properti manual) 
[Klik "Generate Secret 32-Kar" — hanya di memori browser, hilang saat reload]
Referensi Properti Manual di Script Properties 
ADMIN_PASSPHRASE_INIT=<passphrase_min_12_karakter>
ADMIN_PIN_INIT=<6_digit_angka>

FASE 1 • BACKEND GAS

Langkah 4 — Deploy Web App Backend (.../exec)

Tujuan: Menerbitkan satu URL publik .../exec untuk dihubungkan ke frontend.
Aksi: Di pojok kanan atas Editor Apps Script, klik Deploy > New deployment → ikon roda gigi pilih Web app → Execute as: Me → Who has access: Anyone → klik Deploy. Salin URL .../exec ke kotak {{GAS_EXEC_URL}} di atas.
Hasil yang Diharapkan: Endpoint {{GAS_EXEC_URL}} aktif dan siap menerima request POST text/plain.
Sumber: Apps Script Web Apps UNVERIFIED
Cara Update Backend di Masa Depan (URL Tetap): Jangan buat New deployment. Selalu klik Deploy > Manage deployments > Edit (pensil) > Version: New version > Deploy agar URL {{GAS_EXEC_URL}} tidak berubah.

Langkah 5 — Buat Repo GitHub Baru & Upload File Frontend

Langkah 7 — Uji Koneksi Endpoint /exec & Checklist Go-Live

Tujuan: Memastikan frontend di {{PAGES_DOMAIN}} dan backend di {{GAS_EXEC_URL}} saling terhubung mulus.
Aksi: Salin salah satu perintah uji di bawah lalu jalankan di Terminal / PowerShell / DevTools Console (halaman panduan ini tidak melakukan panggilan jaringan).

Sumber: src/core/contract.md 2026-11-28
Jalankan di Terminal
curl -sL -X POST '{{GAS_EXEC_URL}}' \
  -H 'Content-Type: text/plain;charset=utf-8' \
  -d '{"action":"items.list","v":1,"auth":null,"idem":null,"payload":{}}'
Jalankan di Windows PowerShell
$body = '{"action":"items.list","v":1,"auth":null,"idem":null,"payload":{}}'
Invoke-RestMethod -Method Post -Uri '{{GAS_EXEC_URL}}' -ContentType 'text/plain;charset=utf-8' -Body $body
Tempel di DevTools Console pada {{PAGES_DOMAIN}}
fetch('{{GAS_EXEC_URL}}', {
  method: 'POST',
  headers: { 'Content-Type': 'text/plain;charset=utf-8' },
  redirect: 'follow',

}).then(r => r.json()).then(console.log);

Troubleshooting Singkat

1. Di mana Spreadsheet dan Folder Drive yang dibuat setupAppEnvironment()?

Cek panel Execution Log di bagian bawah Editor Apps Script setelah menjalankan setupAppEnvironment()—tautan langsung spreadsheetUrl dan driveFolderUrl dicetak di sana, atau buka Google Drive Saya ↗.

2. Mengapa muncul error CORS saat memanggil /exec dari domain hosting?

Pastikan deployment Web App disetel ke Execute as: Me dan Who has access: Anyone, serta request memakai Content-Type: text/plain;charset=utf-8 tanpa header kustom Authorization.

3. Mengapa update kode di GitHub langsung men-deploy ulang, tapi update kode .gs belum berubah?

Di Apps Script, menyimpan kode (Ctrl+S) belum memperbarui URL /exec. Anda wajib membuka Deploy > Manage deployments > Edit > Version: New version > Deploy.

4. Mengapa hapus data (items.delete) ditolak FORBIDDEN meski sudah login?

Aksi destruktif membutuhkan verifikasi PIN 6 digit (auth.verifyPin → stepUpToken). Pastikan ADMIN_PIN_INIT sudah dikonfigurasi di Langkah 3.
